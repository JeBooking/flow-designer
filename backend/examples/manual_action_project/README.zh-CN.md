# 纯人工动作演练

先按用户手册准备并启动平台，再使用流程目录导入整个目录，让 `workflow.json` 和 `assets/` 下的参考文件一起恢复。本例无需登记 Python 业务工程、准备额外业务解释器或单独启动 worker。

执行后在人工排查选择“是”，结论会继续到人工处置。按参考说明自行模拟操作，核验结果后选择 OK 才会进入“问题解决”。不 OK 会保留同一个任务，不进入后继；可以继续处理后选 OK，也可以回退到之前节点。排查选择“否”则进入升级。

这是独立演练流程，没有真实设备。Cooling 示例使用 `confirm`：模拟 Python 操作只执行一次，随后等待相同的 OK / 不 OK 确认，再执行自动报告。
